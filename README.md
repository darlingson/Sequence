# Sequence

A small practice project for putting complex backend concepts into practical use.

Sequence is a social marketplace where people can find and hire "handymen" — need someone to fix your door (carpenter), repair a tap (plumber), or help with laundry? This is where you find them.

## Features

- Handymen can register on the platform
- Handymen receive ratings from users
- Users can search for handymen
- ...and more

## Tech Stack

| Layer      | Technology |
|------------|------------|
| Backend    | .NET       |
| Frontend   | React (Vite) |
| Database   | PostgreSQL |
| Messaging  | RabbitMQ   |
| Caching    | Redis      |
| Deployment | Docker     |
